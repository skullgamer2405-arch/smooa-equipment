## Brand & Style

ระบบนี้มุ่งเน้นความน่าเชื่อถือและความเป็นมืออาชีพสำหรับการบริหารจัดการอุปกรณ์ภายในชมรม ออกแบบมาเพื่อให้นักศึกษาใช้งานได้ง่ายและรวดเร็ว สไตล์การออกแบบเป็นแบบ **Corporate Modern** ที่เน้นความสะอาดตา (Clean) และเป็นระบบ (Organized) เพื่อลดความผิดพลาดในการกรองข้อมูลและการทำรายการยืม-คืน

อัตลักษณ์ของระบบเน้นความโปร่งใสผ่านการใช้ Whitespace ที่กว้างขวาง และโครงสร้างตารางที่ชัดเจน เพื่อสร้างความรู้สึกมั่นใจและเป็นทางการในฐานะเครื่องมือส่วนกลางของมหาวิทยาลัย

## Colors

ระบบใช้ชุดสีที่สื่อถึงความมั่นคงและพลังงานทางความคิด:
- **Primary (Deep Blue):** ใช้สำหรับโครงสร้างหลัก Navigation, และปุ่ม Action สำคัญ เพื่อสร้างความน่าเชื่อถือ
- **Accent (Vibrant Orange):** ใช้สำหรับจุดที่ต้องการความสนใจเป็นพิเศษ (Call-to-Action) หรือการแจ้งเตือนสำคัญ
- **Status Colors:** ใช้ระบบสีจราจรมาตรฐาน (Semantic Colors) เพื่อบ่งบอกสถานะการยืม-คืนอุปกรณ์อย่างชัดเจน
- **Neutrals:** ใช้สีเทาโทนเย็นสำหรับเส้นขอบ (Borders) และข้อความรอง เพื่อรักษาความสะอาดของอินเทอร์เฟซ

## Typography

การเลือกใช้ฟอนต์เน้นการอ่านออกง่ายในบริบทวิชาการ:
- **Prompt:** ใช้สำหรับหัวข้อ (Headings) เพื่อให้ดูทันสมัยและมีความเป็นทางการในเวลาเดียวกัน
- **Sarabun:** ใช้สำหรับเนื้อหา (Body Copy) และข้อมูลในตาราง เนื่องจากเป็นฟอนต์มาตรฐานที่อ่านง่ายและประหยัดพื้นที่ เหมาะสำหรับการอ่านข้อมูลจำนวนมากบนหน้าจอ
- **Hierarchy:** เน้นการใช้ความหนา (Weight) ที่ต่างกันเพื่อแยกแยะหัวข้อและรายละเอียดข้อมูลอุปกรณ์

## Layout & Spacing

ระบบใช้ **Fluid Grid** 12 คอลัมน์ที่ปรับเปลี่ยนตามขนาดหน้าจอ โดยเน้นระยะห่างที่โปร่งสบาย:
- **Desktop:** ใช้ Container ขนาดสูงสุด 1200px กึ่งกลางหน้าจอ พร้อม Padding ขอบข้างอย่างน้อย 40px
- **Mobile:** ปรับลดระยะ Spacing ลงเหลือระดับ Sm และ Md เพื่อเพิ่มพื้นที่การแสดงผลอุปกรณ์
- **Alignment:** ข้อมูลตัวเลขและรหัสอุปกรณ์ในตารางให้จัดชิดซ้าย (Left-aligned) เพื่อความรวดเร็วในการกวาดสายตาตรวจสอบ

## Elevation & Depth

การสร้างมิติในระบบนี้ใช้เทคนิค **Tonal Layers** ผสมกับ **Ambient Shadows** เพื่อไม่ให้ดูแบนจนเกินไป:
- **Cards:** ใช้เงาฟุ้งกระจาย (Blur 15px, Opacity 5%) พื้นหลังสีขาว บนพื้นสีเทาอ่อนมาก (#F7FAFC) เพื่อให้ดูเหมือนอุปกรณ์วางอยู่บนพื้นผิวจริง
- **Modals:** เพิ่มระดับความเข้มของเงาเพื่อให้ความสำคัญกับหน้าต่างแจ้งเตือนหรือฟอร์มการยืมอุปกรณ์
- **Interactivity:** เมื่อ Hover บนรายการอุปกรณ์ ให้ใช้เงาที่เข้มขึ้นเล็กน้อยเพื่อแสดงสภาวะพร้อมเลือก (Focus state)

## Shapes

รูปทรงขององค์ประกอบ UI เน้นความนุ่มนวลแต่คงความสุภาพ:
- **Radius-XL:** ใช้สำหรับ Container หลัก และการ์ดแสดงผลอุปกรณ์ (ตามค่าตัวแปร `rounded-xl` = 1.5rem)
- **Radius-MD:** ใช้สำหรับปุ่ม Action และ Input fields เพื่อให้ดูเข้ากับรูปทรงหลัก
- **Status Indicators:** ใช้รูปทรงวงกลม (Full rounded) สำหรับจุดแสดงสถานะความพร้อมของอุปกรณ์

## Components

- **Buttons:** ปุ่ม "ยืมอุปกรณ์" ใช้ Primary Color พร้อมตัวอักษรสีขาว ปุ่มรองใช้ Ghost style (เส้นขอบเทา)
- **Inventory Cards:** แสดงรูปภาพอุปกรณ์ด้านบน ข้อมูลชื่อและรหัสตรงกลาง และแถบสีสถานะ (Available/Unavailable) ที่มุมขวาบนอย่างชัดเจน
- **Status Chips:** ใช้พื้นหลังสีจาง (Light Tint) ของสีสถานะนั้นๆ และตัวอักษรสีเข้ม เพื่อความอ่านง่าย
- **Input Fields:** ใช้เส้นขอบสีเทาอ่อน (#E2E8F0) เมื่อมีการ Focus ให้เปลี่ยนเป็นสี Primary Blue พร้อม Shadow เรืองแสงบางๆ
- **Navigation:** แถบเมนูด้านบนแบบ Fixed เพื่อให้เข้าถึงเมนู "รายการที่ยืมอยู่" และ "ประวัติการยืม" ได้ตลอดเวลา
- **Data Table:** สำหรับมุมมอง Admin เน้นการใช้เส้นแบ่งแถวที่บางมากและ Zebra striping (สลับสีแถว) เพื่อให้อ่านข้อมูลรหัสทรัพย์สินได้แม่นยำ
