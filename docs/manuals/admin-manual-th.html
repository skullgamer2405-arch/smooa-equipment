หาคำขอที่ต้องการ

  1. กดแท็บ “คำขอยืม”
  2. เลือกสถานะทางขวาของช่องค้นหา เช่น “รออนุมัติ” “อนุมัติแล้ว” หรือ “คืนแล้ว” หากไม่แน่ใจ ให้เลือก “ทุกสถานะ”
  3. พิมพ์ชื่อผู้ยืม รหัสนักศึกษา ชื่ออุปกรณ์ หรือรหัสอุปกรณ์ในช่องค้นหา
  4. ตรวจทั้งชื่อผู้ยืม รหัสอุปกรณ์ และวันยืมก่อนดำเนินการ เพราะผู้ยืมคนเดิมอาจมีหลายคำขอ
  5. หากไม่พบ ให้ล้างข้อความค้นหา แล้วกดลูกศร “หน้าถัดไป” ที่ด้านล่าง จากนั้นค้นหาในหน้านั้นอีกครั้ง

ทำไมค้นแล้วไม่เจอ

ช่อง “ค้นหาในหน้านี้” ค้นเฉพาะคำขอที่โหลดอยู่ในหน้านั้น คำว่า “ไม่มีคำขอในสถานะนี้” จึงอาจเกิดจากตัวกรองหรือคำค้นที่กำลังใช้

งานที่ยังไม่ได้ตัดสินใจตัวเลข “คำขอรออนุมัติ” หรือกรอง “รออนุมัติ”
ของที่ต้องรับคืนวันนี้ตัวเลข “ครบกำหนดวันนี้”
ของที่เลยวันคืนตัวเลข “เลยกำหนดคืน”

อนุมัติคำขอยืม

  1. เปิดคำขอในสถานะ “รออนุมัติ” แล้วตรวจชื่อผู้ยืม กิจกรรม เหตุผล รหัสอุปกรณ์ และวันยืมถึงวันคืน
  2. ตรวจจำนวนที่ขอยืมเทียบกับจำนวนที่เหลือ และตรวจว่ามีอุปกรณ์พร้อมให้ใช้จริง และวันนัดรับส่งตรงกับที่ตกลงกัน
  3. กด “อนุมัติ” ในรายการนั้น
  4. ในกล่อง “ยืนยันอนุมัติคำขอ” อ่านชื่ออุปกรณ์และผู้ยืมอีกครั้ง ถ้าเลือกผิด ให้กด “ยกเลิก”
  5. ถ้าถูกต้อง กด “ยืนยัน” แล้วรอจนกล่องปิด

SMO.CRA · คู่มือผู้ดูแลการแจ้งเตือนและปฏิทิน

เพิ่มกิจกรรมในปฏิทิน

ชื่อกิจกรรมที่เพิ่มจะแสดงให้ผู้ใช้งานทุกคนเห็น เลือกใช้ชื่อที่เผยแพร่ได้ และหลีกเลี่ยงข้อมูลส่วนตัวของผู้ยืม

  1. เข้าสู่ระบบผู้ดูแล แล้วเปิดเมนู “ปฏิทิน”
  2. กด “เพิ่มกิจกรรม” ด้านบน จะเปิดกล่อง “เพิ่มกิจกรรมในปฏิทิน”
  3. เลือกวันที่ และกรอกชื่อกิจกรรม เช่น “ตรวจสภาพอุปกรณ์ประจำเดือน”
  4. หากต้องการระบุช่วงเวลา ให้กรอก “เวลาเริ่ม” และ “เวลาสิ้นสุด” โดยเวลาสิ้นสุดต้องไม่ก่อนเวลาเริ่ม
  5. เลือก “อุปกรณ์ที่เกี่ยวข้อง” หรือคงเป็น “กิจกรรมทั่วไป”
  6. ตรวจชื่อ วันที่ และเวลา แล้วกด “บันทึกกิจกรรม”
  7. เมื่อเห็น “เพิ่มกิจกรรมเรียบร้อยแล้ว” ให้เลือกวันนั้นในปฏิทินและตรวจรายการที่เพิ่ม

จำไว้ตอนใช้งาน

การเพิ่มกิจกรรมเป็นการแสดงข้อมูลในปฏิทิน ไม่ได้สร้างหรืออนุมัติคำขอยืม และไม่ได้เปลี่ยนสถานะอุปกรณ์ หากต้องการยืม ยังต้องเลือกจำนวน ทำคำขอ และรออนุมัติตามขั้นตอนเดิม

หากพบปัญหาทำอย่างไร
ไม่เห็นปุ่มเพิ่มกิจกรรมตรวจว่าเข้าสู่ระบบด้วยบัญชีผู้ดูแลแล้ว
หาอุปกรณ์ไม่เจอปิดกล่อง แล้วกด “โหลดชื่ออุปกรณ์เพิ่ม” ในหน้าปฏิทินเมื่อมีปุ่มนี้ จากนั้นเปิดกล่องใหม่
เพิ่มแล้วไม่ปรากฏเลือกวันที่ที่บันทึกไว้ และตรวจตัวกรองอุปกรณ์ หากเป็นกิจกรรมทั่วไป ให้ดูทุกอุปกรณ์
พิมพ์ผิดหรือเพิ่มผิดวันหน้าเว็บรุ่นนี้ไม่มีปุ่มแก้หรือลบกิจกรรม ให้แจ้งผู้ดูแลเทคนิคพร้อมชื่อและวันที่
