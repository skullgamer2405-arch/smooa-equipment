# คู่มือผู้ดูแล SMO.CRA

[เปิดคู่มือ PDF ภาษาไทย](../../static/manuals/admin-manual-th.pdf)

คู่มือ 29 หน้า สำหรับผู้ดูแลที่เพิ่งเริ่มใช้ระบบ มีภาพหน้าจอโหมดตัวอย่าง 13 ภาพ ขั้นตอนรับคำขอ รับคืน เพิ่มอุปกรณ์ รูปภาพ QR นำเข้าไฟล์ ปฏิทิน อีเมล LINE และวิธีแก้ปัญหา

อ้างอิงระบบรุ่น `d03ba87fad9a74132490243e4283c379a64c9a46` ฉบับพฤศจิกายน 2569 ตรวจข้อความทั้งหมดตามสกิล Humanizer โดยคงชื่อปุ่มและความหมายของระบบ

ไฟล์ [HTML](admin-manual-th.html) ฝังฟอนต์และภาพไว้แล้ว สามารถดาวน์โหลดแล้วเปิดอ่านในเบราว์เซอร์ได้โดยไม่ต้องโหลดภาพจากภายนอก

ตรวจ PDF: 29 หน้า A4, ฝังฟอนต์, สารบัญ 27 ลิงก์ไปถูกหน้า, ลิงก์เว็บ 6 จุด, แสดงผลครบทุกหน้า ไม่มีข้อความล้นหรือทับส่วนท้ายหน้า ภาพประกอบใช้ข้อมูลจำลองและไม่ได้เชื่อมบริการจริง

PDF ฉบับปรับปรุงครอบคลุมจำนวนทั้งหมด จำนวนที่ขอยืม การทยอยคืน และยอดค้างคืนแล้ว อ่านขั้นตอนเพิ่มเติมใน [คู่มือจำนวนอุปกรณ์และการทยอยคืน](../equipment-quantity.md) สำหรับขั้นตอนนี้
