# ใช้จำนวนอุปกรณ์และรับคืนบางส่วน

## เพิ่มหรือแก้จำนวนอุปกรณ์

1. เข้าหน้าผู้ดูแล แล้วเปิดแท็บ **จัดการอุปกรณ์**
2. กด **เพิ่มอุปกรณ์** หรือ **แก้ไข** รายการเดิม
3. ใส่ **จำนวนทั้งหมด** ด้วยปุ่ม + / − หรือพิมพ์ตัวเลข เช่น มีเก้าอี้ 10 ตัว ให้ใส่ 10
4. จำนวนนี้รวมชิ้นที่มีผู้ยืมอยู่ด้วย ตัวอย่าง: มีทั้งหมด 10 ชิ้น ถูกยืม 3 ชิ้น ให้ใส่ 10 ระบบจะแสดงเหลือ 7 ชิ้น
5. กด **บันทึกอุปกรณ์** รายการเดิมที่ยังไม่ตั้งจำนวนถือว่ามี 1 ชิ้น

สถานะ **พร้อมให้ยืม** เปิดให้ผู้ใช้ขอยืมตามจำนวนที่เหลือ หากยืมหมด ระบบเปลี่ยนเป็น **กำลังถูกยืม** และซ่อนจากรายการอุปกรณ์ของผู้ใช้ ส่วน **อยู่ระหว่างซ่อม** จะปิดการยืมทั้งรายการ

## ผู้ใช้เลือกจำนวนที่ขอยืม

1. ดูข้อความ **เหลือ … จาก … ชิ้น** บนรายการอุปกรณ์
2. กด **ขอยืมอุปกรณ์นี้** แล้วเลือก **จำนวนที่ขอยืม** ด้วยปุ่ม + / − หรือพิมพ์จำนวน
3. กรอกวันและข้อมูลผู้ยืม ตรวจจำนวนในช่อง **ตรวจคำขอก่อนส่ง** แล้วส่งคำขอ

ระบบหักจำนวนเมื่อผู้ดูแลอนุมัติ คำขอที่รออนุมัติยังไม่กันของ หากมีผู้อื่นได้รับอนุมัติก่อนจนของเหลือไม่พอ ระบบจะให้ผู้ดูแลตรวจคำขออีกครั้ง

## รับคืนบางชิ้น

1. เปิดแท็บคำขอยืม เลือกดูรายการที่ **อนุมัติแล้ว** แล้วหาคำขอของผู้ยืมคนนั้น
2. นับของที่ได้รับจริง จากนั้นกด **รับคืน** ในคำขอนั้น
3. ช่อง **จำนวนที่รับคืนครั้งนี้** เริ่มต้นเท่ากับจำนวนที่ยังค้าง เปลี่ยนเป็นจำนวนที่ได้รับจริงก่อนกด **ยืนยัน**
4. เช่น ยืม 5 ชิ้น วันนี้คืน 2 ชิ้น ให้ใส่ 2 ระบบจะเพิ่มของพร้อมให้ยืม 2 ชิ้น และแสดง **คืนแล้ว 2 ชิ้น · ค้างคืน 3 ชิ้น**
5. ให้ผู้ยืมเปิด **รายการยืมของฉัน** แล้วกด **อัปเดตรายการ** เพื่อตรวจยอดล่าสุด
6. เมื่อคืนส่วนที่เหลือ ให้ทำซ้ำโดยระบุเฉพาะจำนวนที่ได้รับครั้งใหม่ เมื่อครบแล้วสถานะจึงเปลี่ยนเป็น **คืนแล้ว**

คำขอที่ยังค้างคืนจะได้รับการเตือนตามกำหนดเดิม โดยข้อความแจ้งจำนวนที่ค้างอยู่ หากคืนครบแล้วจะหยุดเตือนรอบถัดไป ข้อความที่ส่งไปก่อนรับคืนยังอยู่ในแชท

ปุ่ม **รับคืน** ในแท็บ **จัดการอุปกรณ์** จะพาไปหน้าคำขอยืมและค้นหารหัสอุปกรณ์ให้ เลือกคำขอของผู้ยืมแล้วระบุจำนวนที่ได้รับจริง หากยังไม่พบ ให้เปิดคำขอหน้าถัดไป การรับคืนหนึ่งคำขอจะไม่ปิดคำขอของคนอื่น

## เมื่อบันทึกไม่ได้

| ข้อความหรืออาการ | วิธีทำต่อ |
| --- | --- |
| จำนวนทั้งหมดน้อยกว่าที่กำลังถูกยืม | ตรวจของทั้งหมดรวมชิ้นที่อยู่กับผู้ยืม อย่าลดจำนวนเพื่อบันทึกการรับคืน ให้กดรับคืนในคำขอ |
| จำนวนรับคืนเกินจำนวนค้าง | อาจมีผู้ดูแลอีกคนรับคืนแล้ว โหลดรายการใหม่ก่อนทำต่อ |
| เหลือไม่พอสำหรับอนุมัติ | ตรวจคำขอที่อนุมัติแล้ว รอของคืน หรือไม่อนุมัติพร้อมแจ้งเหตุผล |
| กดลบไม่ได้เพราะยังมีผู้ยืม | รับคืนให้ครบก่อนลบ อย่าลบคำขอเพื่อแก้ยอด |
| กดรับคืนแล้วการเชื่อมต่อขัดข้อง | ลองยืนยันซ้ำในหน้าต่างเดิมโดยไม่เปลี่ยนจำนวน ระบบใช้รหัสเดิมป้องกันบันทึกซ้ำ |

ไฟล์นำเข้าเพิ่มคอลัมน์ **จำนวน** ได้ หากไม่มีคอลัมน์นี้จะใช้ 1 ชิ้นต่อรายการ รับเฉพาะจำนวนเต็ม 1–10,000

## สำหรับผู้ดูแลเทคนิค

- Deploy โค้ด app และ api รุ่นเดียวกันก่อน แล้วเผยแพร่ `firestore.rules` ของรุ่นนี้ ปิดการเขียน equipment จาก client โดยตรง ทุกการเพิ่ม/แก้/ลบผ่าน API ผู้ดูแลที่ตรวจ admin claim และ email_verified
- Firestore ไม่มีการย้ายหรือลบข้อมูลเดิมอัตโนมัติ จำนวนอุปกรณ์และคำขอที่ไม่เคยมี quantity จะเท่ากับ 1; returnedQuantity ของคำขอ returned เดิมถือว่าคืนครบ
- ใช้ index เดิม `bookings(equipmentId,status)` ไม่มีตัวแปรสภาพแวดล้อมหรือแพ็กเกจใหม่
- อย่าแก้ quantity, borrowedQuantity หรือ returnedQuantity ตรงใน Console เพื่อรับคืน เพราะจะข้าม transaction และประวัติรับคืน `equipmentReturns` เป็นข้อมูลเฉพาะเซิร์ฟเวอร์
- ระบบอนุมัติได้สูงสุด 100 คำขอที่ยังไม่คืนต่ออุปกรณ์เพื่อจำกัดงานใน transaction เมื่อเต็มยังรับคืนและแก้จำนวนได้ แต่ต้องรับคืนให้ครบอย่างน้อยหนึ่งคำขอก่อนอนุมัติเพิ่ม
- ห้าม rollback ไปโค้ดที่ไม่รองรับจำนวนหลังมีคำขอหลายชิ้นหรือคืนบางส่วน เพราะโค้ดเดิมจะรับคืนทั้งรายการ ต้องใช้รุ่นที่รักษาฟิลด์จำนวนและ transaction เหล่านี้

คู่มือ PDF แอดมินเดิมยังใช้สำหรับเมนูทั่วไป ส่วนการตั้งจำนวนและรับคืนบางส่วนให้ใช้ขั้นตอนในหน้านี้
