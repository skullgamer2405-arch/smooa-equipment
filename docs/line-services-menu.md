# Rich Menu บริการสโมสรฯ

ภาพ `static/line-services-menu.png` ขนาด 2500 × 843 พิกเซล ใช้เทมเพลต LINE OA แบบเตี้ยสามช่องเท่ากัน ฟอนต์ Chulabhorn Likit Text Regular จากไฟล์ต้นฉบับของโปรเจกต์ น้ำหนัก 400 ไม่มีตัวหนาสังเคราะห์

| ตำแหน่ง | ข้อความบนภาพ | Action | URL |
| --- | --- | --- | --- |
| ซ้าย: x 0–832 | ยืม–คืน อุปกรณ์ | Link | `https://liff.line.me/2012301583-jh9GdpQ2/equipment.html` |
| กลาง: x 833–1665 | ติดตาม โครงการ | Link | รอ URL เว็บไซต์ Tracking โครงการจากเจ้าของ |
| ขวา: x 1666–2499 | Voice Box — ส่งความคิดเห็น | Link | รอ URL เว็บไซต์ Voice Box จากเจ้าของ |

ใช้ชื่อเมนู `SMO OA — บริการสโมสรฯ` และข้อความแถบเมนู `บริการสโมสรฯ` พื้นที่กดสูง 843 พิกเซลทุกช่อง ภาพไม่มี URL ฝังอยู่ ต้องใส่ Action ของแต่ละช่องใน LINE OA Manager แยกกัน เปิดแสดงหลังตรวจปลายทางจริงครบทั้งสามช่องและผ่านขั้นตอนเปิดระบบหลักใน `production-setup.md`

แนวออกแบบ: ใช้สีพื้นกรมท่า `#112c44` งาช้าง `#f3efe5` และทองหม่น `#d7ba7e` แยกงานทั้งสาม พร้อมสัญลักษณ์แลกเปลี่ยนอุปกรณ์ ลำดับความคืบหน้า และกล่องข้อความ ตัวอักษรหลักขนาด 132 พิกเซล ข้อความรอง Voice Box ขนาด 112 พิกเซลบนต้นฉบับ จัดช่องเต็มพื้นที่ตามขนาดที่ผู้ใช้ต้องกดใน LINE

สร้างภาพใหม่ด้วย `node scripts/build-line-services-menu.mjs` ในสภาพแวดล้อมทดสอบที่แยกจากข้อมูลจริงและปิดเครือข่าย ใช้ Chromium ที่ติดตั้งแล้วผ่าน `CHROMIUM_PATH` ได้ สคริปต์ตรวจฟอนต์จริง น้ำหนัก ขอบเขตข้อความ ขนาดพื้นที่กด และขนาดไฟล์ก่อนบันทึก ไม่มีการเรียก LINE API หรือเปิดเมนูจริง

ที่มาภาพ: ออกแบบองค์ประกอบและสัญลักษณ์เรขาคณิตในสคริปต์ แล้วเรนเดอร์ HTML ด้วย Chromium ภาพสร้างด้วย image generation ในแชตใช้สำรวจทิศทางเท่านั้น ตัวอักษรในไฟล์ใช้งานจริงเรนเดอร์จากฟอนต์ที่ผู้ใช้ให้ ไม่ได้ใช้ตัวอักษรจากภาพร่าง แนวทางการจัดลำดับและความชัดเจนประยุกต์จาก Impeccable และ design-taste-frontend โดยรักษาสีและฟอนต์ของโปรเจกต์
